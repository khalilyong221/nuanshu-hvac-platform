# 暖枢 NUANSHU — 三端物联网暖通运维平台

一个原创的 IoT / HVAC（暖通空调）运维平台演示项目，模拟服务商、业主、硬件设备三个终端如何围绕同一套设备状态协同工作。每个终端都是独立、可直接在浏览器打开的静态 HTML 页面（无需构建、无外部依赖），并额外提供一个作品集展示页汇总全部内容。

## 设计系统

业主端小程序与硬件中控面板共用同一套设计 token（通过 CSS 自定义属性实现明暗双主题）；服务商中控台作为运营大屏，单独使用一套深蓝配色：

- 字体：Oswald（展示型标题）+ IBM Plex Sans（正文）+ IBM Plex Mono（数据 / 代码感元素）
- 业主端 / 硬件面板：暖米色底、黄铜色（brass）强调，`:root` 定义浅色，`prefers-color-scheme: dark` 与 `[data-theme="dark"]` 覆盖深色
- 服务商中控台：深蓝数据大屏——深海军蓝底色，叠加顶部蓝色光晕与细网格，亮蓝强调；`[data-theme="light"]` 提供淡蓝浅色版
- 语义色：good / warn / critical（状态色），图表分类色 `--cat1` ~ `--cat5`
- 地图：省界与南海诸岛数据来自阿里云 DataV.GeoAtlas，主图右下角附南海诸岛小图；地图为示意用途
- 页面右上角均提供主题手动切换

## 核心功能

- **跨端联动叙事**：三端围绕同一套虚拟住宅的设备状态展开（同一地址、同一天气、同一批传感器读数），模拟真实场景下服务商后台、业主小程序、硬件面板三者数据同步的效果。
- **用电量分析**：新增电表模块，支持"今日 / 近7天 / 近30天"三种周期的用电曲线，叠加峰 / 平 / 谷分时电价信息，并根据当前时间高亮所处电价时段（业主端小程序与硬件面板均实现，数据结构一致）。
- **项目分布地图**：服务商中控台新增全国项目分布地图，16 个重点项目按运行状态（正常 / 预警 / 故障）着色、按设备规模定大小；点击大区或项目可与网点列表、项目详情联动，并显示大区运营中心到项目的服务连线。
- **用气分析**：业主端小程序新增燃气表模块，支持今日 / 近7天 / 近30天用气柱状图（区分采暖热水与炊事），并展示居民阶梯气价与年度档位进度。
- **重点项目**：服务商中控台中「星海国际公寓」作为重点项目，展示 12 台设备的完整清单与项目配置表。
- **智能家居与安防（三端同步）**：星海国际公寓接入智能门锁（开关门动作检测）、分区摄像头、烟雾报警器、燃气探测器、智能窗帘（开合 10%–90%）和分区灯带 / 筒灯。业主端与硬件面板可以操作，服务商中控台实时查看并可对报警一键派单；在同一浏览器中同时打开三端页面，状态会通过 localStorage 实时同步。
- **新建项目（业主端发起 → 服务商受理）**：项目只能由业主在小程序中创建（首页「＋ 新建项目」或「我的」页），填写家庭名称、省市与详细地址、房屋类型、面积、房间数、暖通需求、联系人与期望上门时间，按省份就近分配到 6 大区运营中心。服务商中控台实时出现该项目（地图紫色新建点、待处理项目、项目列表，并计入接入项目统计），受理后自动生成上门勘测工单；业主端同步显示安装进度与负责技师。同一浏览器内通过 localStorage 实时同步。
- **告警与工单联动**：服务商中控台模拟设备异常告警触发工单流转。
- **响应式布局**：三端页面均适配手机宽度（~400px）及桌面宽度，暗色模式经过独立设计与校验。

## 本地查看

无需安装依赖或启动构建流程，直接用浏览器打开对应的 `.html` 文件即可（部分交互效果建议使用 Chrome / Edge 等现代浏览器）。

## 技术说明

纯原生 HTML / CSS / JavaScript 实现，未使用任何前端框架或打包工具，便于直接阅读源码了解实现细节。每个页面自带完整的设计 token、组件样式与交互逻辑。
